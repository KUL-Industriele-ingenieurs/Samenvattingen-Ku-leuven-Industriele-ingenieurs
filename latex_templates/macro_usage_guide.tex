\subsection{Document klassen: article vs report}

\begin{schoolconcept}[Welke documentclass kiezen?]
\begin{description}[leftmargin=2.5cm]
    \item[\texttt{article}] Voor korte documenten, samenvattingen \textbf{zonder} hoofdstukken
    \item[\texttt{report}] Voor langere documenten \textbf{met} hoofdstukken (\verb|\chapter{}|)
\end{description}
\end{schoolconcept}

\begin{theorie}[Structuurverschillen]
\textbf{article class:}
\begin{itemize}[leftmargin=1.5cm]
    \item Hoogste niveau: \verb|\section{}| (in TOC als hoofdniveau)
    \item Geen \verb|\chapter{}| beschikbaar
    \item Ideaal voor samenvattingen van 5--30 pagina's
\end{itemize}

\textbf{report class:}
\begin{itemize}[leftmargin=1.5cm]
    \item Hoogste niveau: \verb|\chapter{}| (in TOC als hoofdniveau)
    \item Secties genummerd per chapter: 1.1, 1.2, ...
    \item Ideaal voor uitgebreide documenten 30+ pagina's
\end{itemize}
\end{theorie}

\subsection{Nieuwe regel of nieuwe alinea?}
In Word druk je gewoon op enter. In LaTeX werkt het anders:

\begin{itemize}
    \item \textbf{Nieuwe alinea:} Laat \textbf{één witregel} open in je code. Dit is de standaard manier!
    \item \textbf{Harde enter:} Gebruik \texttt{\textbackslash\textbackslash} aan het einde van een regel. Doe dit spaarzaam!
    \item \textbf{Newline:} Gebruik \verb|\\| om een nieuwe regel te maken met een extra tab eronder om een alina 
    te maken. Zoals dit\\

    ta da hier is nu een nieuwe regel

    Je kunt ook gewoon een lege regel laten voor een nieuwe alinea maar in sommige box omgevingen werkt dat niet.
    \item \textbf{Nieuwe pagina:} Gebruik \texttt{\textbackslash newpage}.
\end{itemize}

\section{Samenwerken en Issues (GitHub)}
\label{sec:github}
% =============================================================================

Samenwerken aan deze samenvattingen gebeurt via GitHub. We gebruiken de VS Code extensie \textbf{GitHub Pull Requests and Issues} om dit makkelijk te maken.

\subsection{Issues Aanmaken}

Als je een fout vindt of iets wilt toevoegen, kun je direct vanuit je code een "Issue" aanmaken op GitHub.

\begin{oefenblok}[Stap-voor-stap: Issue maken]
\begin{enumerate}
    \item Typ in je LaTeX bestand een commentaar met \texttt{\% @issue:} of \texttt{\% TODO:}.
    \begin{codeblock}[Voorbeeld]{tex}
% @issue: Voeg meer uitleg toe over entropie hier
% TODO: Controleer deze formule nog eens
    \end{codeblock}
    \item Klik op het lampje \faLightbulb\ dat verschijnt (of druk \texttt{Ctrl+.}).
    \item Kies \textbf{"Create issue from comment"}.
    \item VS Code maakt nu automatisch een taak aan op GitHub die anderen kunnen zien.
\end{enumerate}
\end{oefenblok}

\subsection{Aan een Issue Werken}

Wil je een taak oppakken? Dat kan ook direct in VS Code.

\begin{enumerate}
    \item Ga naar de \textbf{Source Control} tab (links, met het vertakking-icoon).
    \item Kijk onderaan bij \textbf{GitHub / Issues}.
    \item Rechtsklik op een issue en kies \textbf{"Start Working on Issue"}.
    \item VS Code maakt automatisch een nieuwe \textit{branch} aan zodat je veilig kunt werken zonder de hoofdversie te breken.
\end{enumerate}

\subsection{Klaar? Pull Request!}

Als je klaar bent met je wijzigingen:

\begin{enumerate}
    \item Commit je wijzigingen ("Commit \& Push").
    \item Er verschijnt een knop \textbf{"Create Pull Request"}.
    \item In de beschrijving van je PR kun je het issue automatisch sluiten door te typen:
    \begin{verbatim}
    Fixes #123
    \end{verbatim}
    (waarbij 123 het nummer van je issue is).
\end{enumerate}

\subsection{Oefenblok (Oefeningen)}

\begin{oefenblok}[Oefening 1.1]
\textbf{Gegeven:} $m = \SI{5}{kg}$, $v = \SI{10}{m/s}$

\textbf{Gevraagd:} Bereken de kinetische energie.

\textbf{Oplossing:}
\[ E_k = \frac{1}{2}mv^2 = \frac{1}{2} \times \SI{5}{kg} \times (\SI{10}{m/s})^2 = \SI{250}{J} \]
\end{oefenblok}

\subsection{Voorbeeld (Praktijkvoorbeelden)}

\begin{voorbeeld}[Praktisch voorbeeld: Fietser]
Een fietser met massa \SI{80}{kg} rijdt met \SI{25}{km/h}. 
De kinetische energie is:
\[ v = \SI{25}{km/h} = \SI{6.94}{m/s} \]
\[ E_k = \half \times 80 \times 6.94^2 = \SI{1930}{J} \approx \SI{1.9}{kJ} \]
\end{voorbeeld}

\subsection{Standaard Figuur}
Gebruik de standaard \texttt{figure} omgeving. Dit geeft je de meeste controle.

\begin{codeblock}[Standaard Figuur]{tex}
\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.8\linewidth]{afbeelding.png}
    \caption{Onderschrift}
    \label{fig:label}
\end{figure}
\end{codeblock}

\begin{waarschuwing}[Waar komt mijn figuur? (htbp)]
LaTeX bepaalt automatisch de beste plek. Met \texttt{[htbp]} geef je jouw voorkeuren aan:
\begin{itemize}
    \item \texttt{h} (here): Hier, op de plek van de code (als er ruimte is).
    \item \texttt{t} (top): Bovenaan de pagina.
    \item \texttt{b} (bottom): Onderaan de pagina.
    \item \texttt{p} (page): Op een aparte pagina (als de figuur groot is).
\end{itemize}
\textbf{Advies:} Gebruik altijd \texttt{[htbp]}. Dit geeft LaTeX de meeste vrijheid om de bladspiegel mooi te houden.
\end{waarschuwing}

\subsection{Harde grens: \textbackslash FloatBarrier}
Soms drijven figuren te ver weg, bijvoorbeeld naar de volgende sectie waar ze niet horen.
Met het commando \texttt{\textbackslash FloatBarrier} (van het \texttt{placeins} pakket) dwing je LaTeX om alle nog niet geplaatste figuren \textbf{nu} te plaatsen voordat de tekst verder gaat.

\begin{codeblock}[FloatBarrier Gebruik]{tex}
... tekst met figuren ...

\FloatBarrier % Alle figuren worden HIER geplaatst

\section{Nieuwe Sectie}
\end{codeblock}

\textit{Tip: In \texttt{school-macros} wordt dit automatisch gedaan voor elk nieuw hoofdstuk (\texttt{\textbackslash chapter}), maar binnen secties moet je het soms zelf doen.}

\subsection{Tekstomloop (Wrap Figures)}
Wil je tekst naast een afbeelding? Gebruik \texttt{wrapfigure} uit het \texttt{wrapfig} pakket.
Dit is handig om ruimte te besparen, maar gebruik het alleen als je voldoende tekst hebt om langs de afbeelding te lopen.

\begin{codeblock}[Wrap Figure]{tex}
% [12] = Aantal regels (optioneel, voor manuele hoogte)
% {r}  = Rechts {l} = Links
% {0.4\linewidth} = Breedte
\begin{wrapfigure}[12]{r}{0.4\linewidth}
    \centering
    \includegraphics[width=\linewidth]{afbeelding.png}
    \caption{Onderschrift}
\end{wrapfigure}
Hier komt je tekst die naast de afbeelding loopt...
\end{codeblock}

\begin{waarschuwing}[Wrapfigure Tips]
\begin{itemize}
    \item \textbf{[lines]}: Het eerste optionele argument (bijv. \texttt{[12]}) dwingt LaTeX om ruimte te reserveren voor exact zoveel regels tekst. Gebruik dit als LaTeX de hoogte verkeerd inschat.
    \item Gebruik \texttt{wraplines} optie van wrapfig niet tenzij nodig.
    \item Als tekst overlapt, gebruik \verb|\vspace{}| na de figuur of gebruik een \texttt{minipage}.
    \item Wrapfigures werken het best in normale tekst, vermijd ze vlak voor sectiekoppen of lijsten.
\end{itemize}
\end{waarschuwing}

    \end{itemize}
