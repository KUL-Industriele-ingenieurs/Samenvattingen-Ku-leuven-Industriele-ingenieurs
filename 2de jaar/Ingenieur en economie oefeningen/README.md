# Ingenieur en economie

> 2de jaar · gemaakt in **LaTeX** · status: af (eerste samenvattingen van dit project)

Dit is samen met [Productietechnologie](../Productietechnologie/README.md) één van
de **eerste twee samenvattingen** waarmee dit project begon — nog volledig in
LaTeX, vóór de overstap naar Typst. Het vak draait grotendeels rond oefeningen,
dus deze samenvatting is uitgewerkt-oefeninggericht en heeft een apart formularium.

## Bestanden

- `Ingenieur&economie-Samenvatting-RubenRyckaert.tex` — de samenvatting (LaTeX-bron)
- `Formularium Ingenieur en Economie.pdf` — formularium
- `assets/` — afbeeldingen

## Compileren

LaTeX-project (zie [LATEX.md](../../LATEX.md) voor de setup):

```bash
latexmk -pdf "Ingenieur&economie-Samenvatting-RubenRyckaert.tex"
```
